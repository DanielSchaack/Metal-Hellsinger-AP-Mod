# Metal-Hellsinger-AP-Mod

Archipelago based randomizer for Metal: Hellsinger

## How do I set up this mod/randomizer?

Feel free to take a look at [the setup guide](./SETUP.md) or to ask questions in the [Archipelago Discord](https://discord.gg/archipelago) thread (see Future Game Design -> Metal: Hellsinger)

## What does randomization do to this game?

In the Metal: Hellsinger Randomizer, every item in the game can be randomized. All Hells, Torments, Weapons, Songs, Outfits, Coat of Arms and Multiplier Pickups can be randomized, as well as player abilities like Jumping, Reloading, Dashing and destroying in-game destructibles.<br>

Ability shuffling is an option available from the options page to shuffle certain abilities
(Jumping, Reloading, Ultimates, Dashing, Slaughter and destroying in-game destructibles),
preventing them from being used until they are unlocked.<br>

## What does this mod offer outside of the Archipelago Randomizer integration?

This mod also includes customization in configuration, such as:

- Enabling the hidden weapons from the Leviathan mode
- Excluding Paz and or Terminus from Hells
- Activating constant Weapon Trickery for all modes
- Enabling Archdevil versions of torments/challenges
- Randomizing outfits on Hells loading
- Randomizing main and boss songs for the Hells mode, including a whitelist in randomization
- Dispensing random items such as voicelines, multiplier pick ups or speed ups/downs during gameplay

## What happens to my save file?

Your save file is safe! But to be sure, you should still make a backup of it. You may find the save files under `%USERPROFILE%\AppData\LocalLow\TheOutsiders\Metal\`

This mod creates a virtual save file when it is loaded, while disabling any and all saving capabilities. _This also includes any progress for the Leviathan mode!_
The virtual save enables all Hells, Torments/Challenges and difficulties by default as well as granting 4000 void orbs for the leviathan mode to create any build you want.

## I don't own any DLC, does this mod enable them?

No, this would be against the author's moral code.
Any and all configurations or randomization therefore respects the required owning of its DLC. If the DLC is not owned, the options either fall back onto a default or straight up don't allow access to certain inventory.

## When I finish a Hell, the game says the assist mode 'Always on Beat' was active despite me not enabling it?

That is intended behaviour. To prevent any form of cheating on the leaderboards while using this mod, the mod internally enables that flag to make use of the game's mechanism to not update leaderboards.
